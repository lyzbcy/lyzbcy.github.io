# 🐟 捞鱼软件中心

**捞鱼软件中心（Laoyu Software Center）** 是开发者捞鱼（lyzbcy）的个人软件合集站，页面名「捞鱼妙妙工具」，收录他自己打磨、天天在用的 Agent Skills、桌面软件、趣味测试和学习资料。所有内容免费使用，开源部分托管在 GitHub。

## 收录内容

- **AI Skills**：自动写实验报告、番茄小说自动写作发布、抖音评论自动回复、学习地图、视频生成提示词润色、QQ 自动收发等
- **软件合集**：捞鱼桌脚看电视（小窗看视频 + 老板键）、网络检查与保活、屏幕开关、捞鱼同步小助手（Syncthing 中文套壳）、自动续火花（QQ + 抖音每日互动）、一键投递、表情包制作等
- **趣味测试**：高考时光机、嘉豪值测试、方便面排名、江南大学食堂档口排名
- **学习资料**：操作系统、Vue3、Python 等学习地图
