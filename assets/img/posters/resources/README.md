# 一图流可复用资源

- `stickers/`：用户现有「星星布丁 / 微信表情包 / 所有表情 / 精选」中的 7 张素材，按用户要求随博客一图流生成器保存。用于本博客海报；不额外声明第三方素材的版权授权。
- `fonts/NotoSansSC[wght].ttf`：Google Fonts Noto Sans SC，源 https://github.com/google/fonts/tree/main/ofl/notosanssc ，许可见 OFL.txt。
- `fonts/NotoEmoji[wght].ttf`：Google Fonts Noto Emoji，源 https://github.com/google/fonts/tree/main/ofl/notoemoji ，许可见 OFL-emoji.txt。

中文与原评价里的 Emoji 使用固定字体；评分星形直接绘制。生成器缺素材或缺字时失败，不静默省略。
